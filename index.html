Privacy Policy for Avidrive

Effective Date: September 6, 2026 | App Name: Avidrive (com.avidrive.app)

Overview

Avidrive is an Android cloud media player and gallery application designed to allow users to view, browse, and stream their personal photos and video files directly from their own Google Drive account on-demand.

We believe in total user privacy. Avidrive operates with zero external servers, zero advertising, and zero data tracking.

Google User Data We Access

Avidrive requests the following Google OAuth scope:

  • https://www.googleapis.com/auth/drive.readonly — Used exclusively to list folders and media metadata (such as file names, image dimensions, and video durations) and to stream video/photo content directly to your device.

Avidrive requests strictly read-only access. The app does not have permission to modify, upload, overwrite, or delete any files in your Google Drive.

How We Use Google User Data

Google user data is used solely to provide core application features:

  • Displaying the user's Google Drive photo and video files within the in-app gallery.
  • Streaming video files with hardware controls (brightness and volume adjustments).
  • Displaying full-resolution photos with pinch-to-zoom capabilities.
  • Navigating folder hierarchies in the user's Drive.

Sharing, Transfer, and Disclosure of Google User Data

Avidrive does NOT share, transfer, sell, rent, or disclose Google user data or Google Drive content with any third parties, external servers, advertising networks, analytics platforms, or data brokers under any circumstances.

All network communication occurs directly and securely between the Avidrive mobile application on your device and Google's official API servers (https://www.googleapis.com/) over encrypted TLS/HTTPS. No user content or credentials ever pass through or touch any third-party intermediary servers.

Retention and Deletion of Google User Data

Data Retention:
Avidrive does not store, retain, or cache your Google Drive files or personal information on any server. Media content (photos and videos) is loaded directly into volatile device memory (RAM) solely for active viewing and playback and is discarded immediately when closed or when the app is exited.

Data Deletion & Access Revocation:
Users maintain total control over their data and permissions:

  • In-App Session Cleansing: You can purge all active authentication tokens and in-memory caches at any time by tapping "Sign Out" within the application.
  • Device Storage Deletion: You can wipe all local application state and cached thumbnails at any time through Android Settings > Apps > Avidrive > Storage > Clear Storage / Clear Cache.
  • Revoking Google Account Access: You can permanently disconnect Avidrive's access to your Google Account at any time by visiting Google's Third-Party Access Security page at:
    https://myaccount.google.com/permissions.
    Upon revocation, Avidrive will immediately lose all access to your Google Drive.
  • Server Deletion Inquiries: Because Avidrive operates without backend user accounts or databases, there is no persistent server-side user data to delete. If you have any inquiries, contact the developer at avinashrickyy@gmail.com.

Google API Services User Data Policy Compliance

Avidrive's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

Security Measures

We implement industry-standard security practices to protect your data. All Google API communications are encrypted in transit via Transport Layer Security (TLS 1.3). Authentication tokens are managed securely through Google Play Services on your Android device.
